Setup Wizard Flow Design

End-to-end first-run onboarding — covering OsmAnd prerequisites, login, and OpenRouter setup

App Flow (with wizard)

Navigation Flow
Splash → First run? → yes → Setup Wizard → Main
Splash → First run? → no → Login → Main
Wizard → skip → Login → AI Welcome → Main

Wizard Steps

Step 1: Welcome

Welcome to PEVPlugShare

This wizard will help you set up everything you need. PEVPlugShare uses OsmAnd for location storage and OpenRouter for AI-powered features.

We'll walk you through:

  • Installing OsmAnd (map app)
  • Creating an OsmAnd account
  • Setting up a favourites folder
  • Syncing to OsmAnd Cloud
  • Connecting your OsmAnd account
  • Setting up AI features (optional)
Step 2: Install OsmAnd

Install OsmAnd

OsmAnd is the map application PEVPlugShare uses to store and sync your EV charger locations.

✓ OsmAnd+ detected on this device

— or if not installed —

OsmAnd is not installed

Step 3: Log into OsmAnd

Log into OsmAnd

You need an OsmAnd Cloud account to sync locations. Open OsmAnd and sign in or create an account:

  1. Open OsmAnd on your device
  2. Tap the menu (☰) button
  3. Tap Settings
  4. Tap OsmAnd Cloud
  5. Sign in or Create account
Step 4: Create Favourites Folder

Create a Favourites Folder

PEVPlugShare stores charger locations in a dedicated OsmAnd favourites folder (not the default "Favourites").

  1. In OsmAnd, tap My Places
  2. Go to the Favourites tab
  3. Tap + to add a favourite
  4. In the folder field, create a new folder (e.g. "EV Chargers")
  5. Save the favourite (you can delete it later)
Step 5: Sync to Cloud

Sync to OsmAnd Cloud

Sync your favourites so PEVPlugShare can access the folder via the OsmAnd Cloud API.

  1. Open OsmAnd Settings
  2. Tap OsmAnd Cloud
  3. Tap Sync now
  4. Wait for sync to complete

The sync uploads your new folder so PEVPlugShare can find it when you connect your account.

Step 6: Connect OsmAnd Account

Connect Your Account

Enter your OsmAnd credentials to connect PEVPlugShare to your cloud account.

On success: fetches categories, confirms folder exists, auto-advances.

Step 7: OpenRouter AI (Optional)

AI Features (Optional)

PEVPlugShare can use AI to analyse charger photos, detect socket types, and extract operating hours.

This requires a free OpenRouter.ai account.

Step 8: All Done!

You're All Set!

✓ Favourites folder created
✓ Cloud synced
✓ Account connected
◯ OpenRouter — skipped

Key Design Decisions

  • Single Activity + ViewPager2 — swipeable steps with a progress indicator at the top
  • Step 2 auto-detects OsmAnd installation — checkbox auto-ticks if detected
  • Step 6 actually logs in — reuses existing LoginViewModel, validates session + fetches categories
  • Step 7 absorbs AiWelcomeActivity — same OAuth flow, embedded in wizard
  • Skip wizard at any time — button visible on all steps, falls through to Login → AiWelcome → Main
  • Checklist on each step — user confirms completion before advancing
  • Back navigation — allowed to revisit previous steps
  • First-run flag — stored in SharedPreferences, wizard never shown again
