Step 7: Verify Favourites Folder (New)

Three possible states after checking the API

State A: Folder Found

Select Your PEV Folder

We found the following favourites folders in your OsmAnd Cloud account (the default "Favourites" folder is excluded):

● PEV Charging Locations selected
○ Road Trip Stops
○ Camping Sites
State B: No Folders Found

No Favourites Folder Found

We connected to your OsmAnd Cloud account successfully, but couldn't find any favourites folders other than the default "Favourites".

This usually means one of two things:

A) You haven't created the folder yet

  1. Open OsmAnd on your device
  2. Tap My Places (★ star icon)
  3. Go to the Favourites tab
  4. Tap + to add a new favourite point
  5. Create a new folder called "PEV Charging Locations"
  6. Save the point, then sync to cloud (see below)

B) You created the folder but haven't synced yet

  1. Open OsmAnd Settings > OsmAnd Cloud
  2. Tap Sync now
  3. Wait for the sync to complete (green checkmark)

⏰ Note: After syncing in OsmAnd, there can be a delay of 1–2 minutes before the folder appears in the Cloud API. If you've already created the folder and synced, wait a moment and then retry.

Steps 1–6 (unchanged from v2)

Step 1: Welcome

Welcome to PEVPlugShare

PEVPlugShare helps you find and share PEV (Plug-in Electric Vehicle) charging locations with the community.

The app uses OsmAnd to store and sync your charging locations, and OpenRouter for optional AI-powered features.

This wizard will guide you through everything:

  • Installing OsmAnd (map & navigation app)
  • Creating an OsmAnd Cloud account
  • Creating a "PEV Charging Locations" favourites folder
  • Syncing to OsmAnd Cloud
  • Connecting & verifying your account
  • AI features setup (optional)
Step 2: Install OsmAnd

Install OsmAnd

OsmAnd is an open-source map and navigation app. PEVPlugShare uses OsmAnd Cloud to store and sync your PEV charging locations across devices.

✓ OsmAnd+ detected on this device

— or if not installed —

OsmAnd is not installed on this device

Install either OsmAnd or OsmAnd+ from the Play Store, then return here.

Step 3: Log into OsmAnd

Log into OsmAnd

You need an OsmAnd Cloud account so your PEV charging locations can sync. If you don't have one, create a free account inside the OsmAnd app.

In the OsmAnd app:

  1. Open OsmAnd on your device
  2. Tap the menu (☰) button
  3. Tap Settings
  4. Tap OsmAnd Cloud
  5. Sign in or tap Create account
Step 4: Create Favourites Folder

Create "PEV Charging Locations" Folder

PEVPlugShare needs a dedicated favourites folder to store charging locations separately from your personal OsmAnd favourites.

In the OsmAnd app:

  1. Tap My Places (★)
  2. Go to Favourites tab
  3. Tap + to add a new favourite
  4. Create a new folder: "PEV Charging Locations"
  5. Save the point (can delete it later)
Step 5: Sync to Cloud

Sync to OsmAnd Cloud

Upload your new folder to OsmAnd Cloud so PEVPlugShare can access it via the API.

  1. Open OsmAnd Settings > OsmAnd Cloud
  2. Tap Sync now
  3. Wait for the green checkmark
Step 6: Connect Account

Connect Your OsmAnd Account

Enter your OsmAnd Cloud credentials.

On success → auto-advances to folder verification
