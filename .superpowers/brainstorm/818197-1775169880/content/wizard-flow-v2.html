Wizard Steps

Step 1: Welcome

Welcome to PEVPlugShare

PEVPlugShare helps you find and share PEV (Plug-in Electric Vehicle) charging locations with the community.

The app uses OsmAnd to store and sync your charging locations, and OpenRouter for optional AI-powered features like photo analysis and socket detection.

This wizard will guide you through setting up everything you need:

  • Installing OsmAnd (map & navigation app)
  • Creating an OsmAnd Cloud account
  • Creating a "PEV Charging Locations" favourites folder
  • Syncing your folder to OsmAnd Cloud
  • Connecting your OsmAnd account to this app
  • Setting up AI features (optional)
Step 2: Install OsmAnd

Install OsmAnd

OsmAnd is an open-source map and navigation app. PEVPlugShare uses OsmAnd Cloud to store and sync your PEV charging locations across devices.

✓ OsmAnd+ detected on this device

— or if not installed —

OsmAnd is not installed on this device

Install either OsmAnd or OsmAnd+ from the Play Store, then return here.

Step 3: Log into OsmAnd

Log into OsmAnd

You need an OsmAnd Cloud account so your PEV charging locations can sync between the OsmAnd app and PEVPlugShare. If you don't have one yet, you can create a free account inside the OsmAnd app.

In the OsmAnd app:

  1. Open OsmAnd on your device
  2. Tap the menu (☰) button
  3. Tap Settings
  4. Tap OsmAnd Cloud
  5. Sign in with your existing account, or tap Create account to register
Step 4: Create Favourites Folder

Create "PEV Charging Locations" Folder

PEVPlugShare needs a dedicated favourites folder in OsmAnd to store the charging locations you discover and share. This must be a separate folder from the default "Favourites" — it keeps your PEV data organized and lets the app manage it without affecting your other OsmAnd favourites.

In the OsmAnd app:

  1. Tap My Places (★ star icon)
  2. Go to the Favourites tab
  3. Tap the + button to add a new favourite point
  4. In the folder / group field, tap to create a new folder
  5. Name it "PEV Charging Locations" (or any name you'll recognise)
  6. Save the temporary favourite point (you can delete it afterward)

Why a separate folder? PEVPlugShare reads and writes to this folder via the OsmAnd Cloud API. Using a dedicated folder ensures your personal OsmAnd favourites are never modified.

Step 5: Sync to Cloud

Sync to OsmAnd Cloud

Your new "PEV Charging Locations" folder exists locally on your device. You need to sync it to OsmAnd Cloud so that PEVPlugShare can access it via the API.

In the OsmAnd app:

  1. Tap the menu (☰) button
  2. Tap Settings
  3. Tap OsmAnd Cloud
  4. Tap Sync now (or wait for auto-sync)
  5. Wait until the sync completes — look for the green checkmark

Why sync now? PEVPlugShare connects to OsmAnd Cloud (not the local app) to read your folders. If the folder hasn't been synced, it won't appear when you connect your account in the next step.

Step 6: Connect OsmAnd Account

Connect Your OsmAnd Account

Enter the same credentials you used to log into OsmAnd Cloud. PEVPlugShare will verify your account and check that your "PEV Charging Locations" folder is available.

On success, the app will:

  • Log into OsmAnd Cloud API
  • Fetch your favourites categories
  • Confirm folders beyond default "Favourites" exist
  • Let you select your PEV folder in the next step
Step 7: OpenRouter AI (Optional)

AI Features (Optional)

PEVPlugShare can use AI to help you document charging locations:

  • Photo analysis — identify charger types from photos
  • Socket detection — detect plug/socket types automatically
  • Hours extraction — read operating hours from signage

This requires a free OpenRouter.ai account. You can set this up later from Settings if you prefer.

Step 8: All Done!

You're All Set!

Setup complete. Here's your configuration summary:

✓ Logged into OsmAnd Cloud
✓ "PEV Charging Locations" folder created
✓ Synced to OsmAnd Cloud
✓ OsmAnd account connected
◯ OpenRouter AI — skipped (set up later in Settings)
