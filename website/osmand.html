OsmAnd integration

Your charging spots, live in OsmAnd.

PEV PlugShare and OsmAnd are built for the same rider: offline maps, no account required, your data yours. The integration has two halves — navigation handoff in one tap, and two-way favourites sync through an OsmAnd Cloud folder, which is the app's current cloud-sync story.

Favourites sync Navigation

Cloud sync today = OsmAnd favourites. Your locations sync two-way with the OsmAnd favourites folder you choose, riding on OsmAnd Cloud — no separate account to create. Full first-party cloud sync across all your devices, and sharing locations with other riders, is Coming soon.

Two-way favourites sync

Pick an favourites folder in OsmAnd (e.g. "PEV Charging") and PEVPlugShare keeps it current in both directions:

Import

Connect your OsmAnd account (osmand.net) and choose a folder — the app reads the folder's GPX waypoint file from OsmAnd Cloud and pulls every favourite into your local database, ready offline. One-off import per folder, with the folder available as your "Favourite Category".

Write back

When you save a location, the app matches it against your OsmAnd favourites by name and GPS (nearest point within a configurable distance, default 10 m) and pushes an add-or-update into the folder's GPX file through OsmAnd's web API. Background auto-sync picks up anything made while offline (6-hourly worker, plus on-save).

You approve the description

Save triggers an optional "Sync to OsmAnd?" prompt with a "verify description before syncing" checkbox — review the generated description first, or let it push straight through.

Disconnect cleanly

Menu → Disconnect from OsmAnd clears the session and stored credentials, optionally removing OsmAnd-synced locations from the phone. It never deletes anything from your OsmAnd Cloud account.

Setup (driven by the in-app wizard)

  1. Install OsmAnd — the wizard checks for it (free or paid package).
  2. Sign in with your OsmAnd (osmand.net) account.
  3. Create a favourites folder in OsmAnd and back it up to OsmAnd Cloud.
  4. Connect it in PEVPlugShare and pick the folder — new folders take 1–2 minutes to appear in OsmAnd's API.

One-tap navigation

Every location card has a navigation arrow: PEVPlugShare hands the destination to OsmAnd via its deep-link API using the bicycle profile (sensible for unicycles and scooters too), with the map shown on OsmAnd's side if you'd rather preview first. Works with both net.osmand (free) and net.osand.plus (paid). Because it's OsmAnd, the route works with downloaded offline maps — no signal needed at the trailhead.

Coming soon: first-party cloud sync (your own account, all your devices) and sharing locations with other riders — friends, groups, and suggestions. The OsmAnd favourites integration above is how cloud sync works today and will keep working.
