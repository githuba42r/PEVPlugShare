Full source, one repo

Kotlin app, MVVM + Hilt, Room, Retrofit, osmdroid, and the C++ module that keeps OAuth secrets out of managed code — all in one tree with build scripts, tests, and release tooling.

Reproducible releases

./release.sh patch|minor|major bumps version.properties (semver + version code), tags, and builds the signed release artifact. Releases are published on GitHub for sideloading; Google Play distribution is a future stage.

Issues & contributions

Found a socket worth sharing or a bug worth squashing? Open an issue or pull request on GitHub — feature requests for socket types, regions, and integrations are welcome.

Companion services

The OAuth connector that powers AI account linking is open as well: oauth-callback-service/ (FastAPI + Flask, self-hostable).

Current version: 1.3.3 (version code 14) — see version.properties and the git tags in the repository. Prebuilt downloads (signed APK) are at download/PEVPlugShare.apk — always the newest build, published automatically by GitHub Actions on every release tag, alongside the GitHub release.

Build from source

Prerequisites:

  • Android Studio Hedgehog or later
  • Android SDK 36
  • JDK 17
  • CMake 3.22.1 or later (the native C++ module holds the OAuth secrets)

Set up your secrets file, then build:

cp secrets.properties.template secrets.properties # fill in oauth.dev.callback.url, oauth.dev.shared.secret, # oauth.dev.deep.link.scheme (and the oauth.prod.* equivalents) ./gradlew assembleDebug # build the APK ./gradlew installDebug # build + install on a connected device ./gradlew test # unit tests ./gradlew lint # static checks

Releases are cut with the repo's release script, which keeps everything in lock-step:

./release.sh patch # 1.3.3 -> 1.3.4 ./release.sh minor # 1.3.3 -> 1.4.0 ./release.sh major # 1.3.3 -> 2.0.0 ./release.sh minor --pre-release

The script verifies a clean working tree, updates version.properties, commits, tags, and writes release notes. Publishing itself is handled by GitHub Actions, which on every release tag uploads the signed APK to the GitHub release, mirrors it to download/PEVPlugShare.apk, and ships the AAB to the Google Play internal testing track.
