┌─────────────────────────────────────────────────────────────────────────────┐
│ WHAT TO LOOK FOR IN THE LOGS                                              │
└─────────────────────────────────────────────────────────────────────────────┘

✅ SUCCESS MARKERS:
   ✅ ADD FAVORITE - EXACT ALGORITHM ................ Starting add
   ✅ Using updatetime: [timestamp] ................ Got server time
   ✅ ADD SUCCESSFUL! ............................. Request succeeded
   ✅ Found location at index [N] in GPX .......... Location found in response
   ✅ COMPLETE: Location synced to OsmAnd ........ All steps completed

❌ ERROR MARKERS:
   ❌ ADD FAILED: HTTP [code] ..................... Server returned error
   ❌ Could not find location in GPX ............ Location missing after add
   ❌ Exception during add ....................... Code error occurred

⚠️  WARNING MARKERS:
   ⚠️  ERROR 106: File was changed! ............ Timestamp mismatch (will retry)
   ⚠️  Could not download GPX ................. Download failed
   ⚠️  Group doesn't exist yet ................ Will be created

┌─────────────────────────────────────────────────────────────────────────────┐
│ COMMON ISSUES & SOLUTIONS                                                  │
└─────────────────────────────────────────────────────────────────────────────┘

ISSUE #1: "Has token: false"
   CAUSE: User not logged in to OsmAnd
   FIX: Have user login to OsmAnd via Settings > OsmAnd Sync
   CHECK: Look for 🔍 CHECKING AUTHENTICATION section

ISSUE #2: "ERROR 106: File was changed!"
   CAUSE: Timestamp mismatch between app and server
   FIX: System automatically retries (happens up to 2 times)
   CHECK: Watch for second attempt with "Attempt 2 of 2"

ISSUE #3: "Could not download GPX"
   CAUSE: Network error or OsmAnd API down
   FIX: Check internet connection, try again
   CHECK: Look for 📥 RESPONSE RECEIVED section

ISSUE #4: "HTTP 401 Unauthorized"
   CAUSE: Invalid or expired authentication token
   FIX: User needs to re-login to OsmAnd
   CHECK: Compare token length with known good token

ISSUE #5: "Could not find location in GPX"
   CAUSE: Location name mismatch or special character encoding
   FIX: Check if location name has special characters
   CHECK: Compare name being searched with names in GPX

📍 = Location details being processed

Only show success/failure:
  adb logcat com.a42r.pevplugshare:D *:S | grep -E "✅|❌"

Only show errors:
  adb logcat com.a42r.pevplugshare:E *:S | grep "OsmandLocationSync"

Only show API responses:
  adb logcat com.a42r.pevplugshare:D *:S | grep -E "HTTP|RESPONSE|SUCCESSFUL|FAILED"
