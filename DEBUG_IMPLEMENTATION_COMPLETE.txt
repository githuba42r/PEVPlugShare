ISSUE: "Has token: false"
└─ User not logged in to OsmAnd
└─ Fix: Navigate to Settings > OsmAnd Sync > Login


ISSUE: "ERROR 106: File was changed!"
└─ Timestamp mismatch between app and server
└─ Fix: Auto-retry (up to 2 attempts) - watch for "Attempt 2 of 2"


ISSUE: "HTTP 401 Unauthorized"
└─ Invalid or expired authentication token
└─ Fix: User needs to re-login to OsmAnd


ISSUE: "Could not download GPX"
└─ Network error or OsmAnd API issue
└─ Fix: Check internet connectivity, try again


ISSUE: "Could not find location in GPX"
└─ Location name mismatch or character encoding issue
└─ Fix: Check location name for special characters
